# talking-workout-trainer
Interval timer that announces every exercise with an audio signal

**Try it on https://flappix.github.io/talking-workout-trainer**

<img src="https://raw.githubusercontent.com/flappix/talking-workout-trainer/refs/heads/main/screenshot.png" width=300 />

## Features

- Custom workouts with custom exercises
- Voice prompts
  - different voices (browser dependent)
- Customizable work and rest times
  - per workout
  - per exercise
- works on any phone, tablet and desktop
- animated timer
- shuffled workouts
- share workouts via link
- export/import workouts via JSON file
- energy saving mode
- PWA
- no backend needed

Feel free to report bugs and feature requests in the issue tracker.
